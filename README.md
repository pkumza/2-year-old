# 2-year-old

一个给 2岁5个月儿童使用的简短交互式 HTML 课程示例。

## 内容

### 小小互动课 (`index.html`)

- 第 1 课：颜色识别
- 第 2 课：数量感知
- 第 3 课：形状识别
- 第 4 课：大小比较
- 第 5 课：动物声音
- 第 6 课：动作模仿

### 生活小帮手 (`course_daily_life.html`)

- 第 1 课：下雨穿衣
- 第 2 课：睡前刷牙
- 第 3 课：玩具收纳
- 第 4 课：情绪识别
- 第 5 课：洗手动作
- 第 6 课：过马路安全

## 使用

直接用浏览器打开 `index.html` 或 `course_daily_life.html`。
